# imu_position_estimation_demo.py の使用方法

このサンプルコードは、IMUセンサーのデータを使用して位置推定を行うデモプログラムです。

## 必要なライブラリ

```
pip install numpy
```

## 使用方法

1. コードを実行します：
   ```
   python imu_position_estimation_demo.py
   ```

2. プログラムは仮想IMUからのデータを使用して位置推定を行い、結果をリアルタイムで表示します。

## 出力データ

コンソールに以下の情報が表示されます：
- `Position: X=x.xxxm, Y=y.yyym, Z=z.zzzm`: 推定された3次元位置

## 仕組み

1. 仮想IMUクラスが加速度と角速度のデータを生成します
2. IMUPositionEstimatorクラスがこれらのデータを処理します：
   - 姿勢推定（Madgwickフィルタ使用）
   - 重力成分の除去
   - 加速度の二重積分による位置推定

## カスタマイズ

- ノイズレベルを変更するには、`VirtualIMU` のインスタンス化時に `noise_std` パラメータを調整します
- サンプリング間隔を変更するには、`dt` パラメータを調整します
- 実際のIMUセンサーを使用する場合は、`VirtualIMU` クラスを実際のセンサーからデータを取得するコードに置き換えます
