# code_sample_13.py の使用方法

このサンプルコードは、IMUセンサーのノイズレベルを異なる単位で表現する方法を示しています。

## 必要なライブラリ

```
pip install numpy
```

## 使用方法

1. コードを実行します：
   ```
   python code_sample_13.py
   ```

2. 角速度と加速度のノイズレベルが異なる単位で表示されます。

## 出力例

```
角速度ノイズ: 0.010000 deg/s = 36.000000 deg/h
加速度ノイズ: 0.001000 m/s² = 101.936799 μg
```

## 単位変換の仕組み

このコードでは以下の単位変換を行っています：

1. 角速度の単位変換：
   - deg/s（度/秒）から deg/h（度/時）への変換
   - 変換式: deg/h = deg/s × 3600（1時間 = 3600秒）

2. 加速度の単位変換：
   - m/s²（メートル/秒²）から μg（マイクロG）への変換
   - 変換式: μg = (m/s² × 1,000,000) ÷ 9.81（1g = 9.81 m/s²）

## カスタマイズ

- 角速度ノイズレベルを変更するには、`adev_deg_s` の値を調整します
- 加速度ノイズレベルを変更するには、`adev_ms2` の値を調整します
- 異なる単位への変換を追加することもできます（例：rad/s、mg など）
